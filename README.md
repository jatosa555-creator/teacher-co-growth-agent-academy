# Teacher Co-Growth Agent Academy

## Teacher Growth Partner

คู่คิดครูสำหรับปรับบทเรียน สะท้อนการสอน และใช้เช็กลิสต์ต้นฉบับประกอบการพัฒนางาน โดยครูเป็นผู้ตัดสินใจ

Teacher Growth Partner helps teachers improve lesson plans, reflect on classroom evidence, and draft reusable workflows with traceable checklist references.

### Capabilities

- ปรับแผนเดิม กิจกรรม ใบงาน และ exit ticket ตามเวลาและทรัพยากรที่ครูกำหนด
- ตรวจความครบและสิ่งที่ยังต้องยืนยันก่อนนำไปสอน
- ใช้ Classroom Practical Checklist V8 จำนวน 58 รายการ และ AI Teacher Practice จำนวน 70 ข้อสะท้อนคิด + 10 รายการหลักฐาน
- ค้นเกณฑ์ อ่านข้อความรายข้อ และอ้าง PDF พร้อมเลขหน้าผ่าน MCP แบบอ่านอย่างเดียว
- ร่าง Teacher Growth Plan และเครื่องมือใช้ซ้ำที่ครูควบคุมเอง

### Start with one lesson

> ช่วยปรับแผนที่มีให้พร้อมลองสอน โดยคงเวลาและวัสดุเดิม ใช้เช็กลิสต์ของโครงการเลือก 2–3 ข้อและบอกสิ่งที่จะสังเกต

Skills run in a compatible AI host. MCP serves a dated public reference snapshot; it does not read private Drive folders, store lesson plans, call AI models, remember other chats, or establish classroom outcomes.
