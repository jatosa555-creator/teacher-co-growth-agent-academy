## ความคลุมเครือที่เก็บตามต้นฉบับ

คู่มือภาพหน้า 5 ส่วน When Stuck มี Red Flag ว่า “มีคนถูกทำให้มั่นใจ” อ่านจากภาพขยายแล้วยังเป็นข้อความนี้ ซึ่งความหมายไม่สอดคล้องกับหัวข้อ จึงเก็บตามภาพและทำเครื่องหมายให้เจ้าของต้นฉบับตรวจ ห้าม AI แก้เองหรือใช้วลีนี้ตัดสิน ไม่กระทบ 138 รายการที่ตรวจข้อความจาก PDF ได้

## วิธีใช้และต้นทุนบริบท

ครูเริ่มด้วยงานปกติ ระบบเลือก 2–3 ข้อ อ่านเฉพาะไฟล์เสาที่เกี่ยวข้อง แล้วผูกเกณฑ์กับหลักฐานในแผน ข้อเสนอปรับ และสิ่งที่จะสังเกต ไม่โหลด 138 ข้อทุกคำตอบ ไม่บังคับครูกรอกแบบใหม่ ไม่ให้คะแนนผ่านโดยไม่มีรูบริก

แยกสองวิธีตรวจข้อมูล (AI-P1-09 หน้า 1) จากสองรอบ feedback (AI-P2-17 หน้า 3) และแยกรายการหลักฐานออกจากเกณฑ์สะท้อนคิด

## การอัปเดตและ Drive

Google Drive เป็นที่เก็บต้นฉบับอ้างอิง Markdown เป็นรุ่นใช้งานที่บรรจุใน ZIP และแก้ไขได้ใน repository ของโครงการ ไม่จำเป็นต้องสร้าง Google Doc ซ้ำก่อนใช้งาน ถ้าจะให้ทีมแก้บน Drive ภายหลัง ให้กำหนดต้นฉบับหลักและกระบวนการตรวจรุ่นก่อนอัปเดต ZIP เพื่อไม่ให้สองสำเนาคลาดกัน

ไม่มีการอ่าน Drive สดหรือซิงก์บัญชีครูอัตโนมัติ ลิงก์ต้นฉบับอาจต้องขอสิทธิ์อ่านจากเจ้าของ การโหลด Markdown ที่บรรจุแล้วไม่ต้องเชื่อม Drive ส่วนการเชื่อมเอกสารส่วนตัวของครูต้องมี connector และสิทธิ์ตามบัญชีจริง
