# การสนับสนุน / Support

**ผู้เผยแพร่ที่ระบุ:** CHANON PHAJUNDA

สำหรับปัญหาการติดตั้ง การค้นหารายการ หรือการรายงานข้อผิดพลาด ให้เปิด [GitHub Issue ของโครงการ](https://github.com/jatosa555-creator/teacher-co-growth-agent-academy/issues)

## ก่อนเปิด Issue

- ระบุขั้นตอนที่ทำและข้อความผิดพลาด โดยลบ token, URL ส่วนตัว และข้อมูลที่ระบุตัวบุคคลออก
- ใช้รหัสรายการเช็กลิสต์แทนการวางแผนการสอนหรือข้อมูลนักเรียน
- Issues เป็นสาธารณะและจัดเก็บโดย GitHub แยกจากบริการ MCP ห้ามโพสต์ข้อมูลส่วนบุคคลของนักเรียนหรือรายละเอียดอ่อนไหวด้านความเป็นส่วนตัว
- MCP รับคำค้นสั้น ๆ หรือรหัสรายการเท่านั้น และอ่าน snapshot สาธารณะแบบคัดไว้ ไม่ได้อ่าน Drive ส่วนตัว

ไม่มีการประกาศอีเมลสนับสนุน

### English summary

Report setup or catalog issues through the project’s intended GitHub Issues link after verifying it. Issues are public and stored by GitHub. Redact credentials and personal information; never post student personal data or sensitive privacy details. No support email is published.
