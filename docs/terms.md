# ข้อกำหนดการใช้งาน / Terms of Use

**ผู้เผยแพร่ที่ระบุ:** CHANON PHAJUNDA  
**ขอบเขต:** Teacher Growth Partner, Skills และคลัง MCP สาธารณะแบบอ่านอย่างเดียว

ข้อกำหนดนี้อธิบายการใช้งานที่ตั้งใจไว้สำหรับรุ่นออนไลน์ การเผยแพร่และการตั้งค่าจริงยังต้องตรวจสอบก่อนใช้งาน

## ขอบเขตบริการ

คลัง MCP ค้นหาและแสดงรายการจาก snapshot เช็กลิสต์ที่คัดไว้ ไม่ได้เชื่อม Google Drive สดหรือบัญชีส่วนตัว ส่วน Skills ทำงานใน AI host ที่ผู้ใช้เลือก โดยใช้บริบทบทสนทนาปัจจุบันตามความสามารถและนโยบายของ host นั้น Companion workspace เตรียมและตรวจร่างงาน แต่ไม่ได้เรียก AI API เอง ไม่มีการรับรองว่ามีหน่วยความจำข้ามบทสนทนา

## การใช้งานที่เหมาะสม

- ใช้คำค้น MCP เป็นคำสำคัญสั้น ๆ หรือส่งเฉพาะรหัสรายการที่ต้องการอ่าน ห้ามส่งชื่อบุคคล แผนการสอนฉบับเต็ม หรือบันทึกส่วนตัว
- อย่าใส่ข้อมูลส่วนบุคคลของนักเรียนหรือรายละเอียดอ่อนไหวด้านความเป็นส่วนตัวใน GitHub Issues ซึ่งเป็นสาธารณะ
- เคารพข้อกำหนดของ AI host, GitHub และผู้ให้บริการโฮสต์ที่เกี่ยวข้อง การใช้งานผู้ให้บริการเหล่านั้นอยู่ภายใต้เงื่อนไขของผู้ให้บริการแต่ละราย
- ใช้เช็กลิสต์เป็นแนวทางสะท้อนคิด ไม่ถือว่ารายการหลักฐานเป็นเกณฑ์ให้คะแนน และอย่าอ้างผลการเรียนหรือคะแนนทางการที่ไม่ได้ตรวจวัด

## ความรับผิดชอบและที่มา

ครูยังคงใช้ดุลยพินิจทางวิชาชีพ ตรวจสอบคำแนะนำและแหล่งอ้างอิง แล้วตัดสินใจเองก่อนนำไปใช้กับผู้เรียน เครื่องมือไม่ยืนยันความเหมาะสมต่อบริบทเฉพาะ ผลการสอน หรือการเปลี่ยนแปลงในชั้นเรียน

รายการความรู้มาจาก snapshot ของ [Classroom Practical Checklist V8 และ AI Teacher Practice Checklist](submission/CHECKLIST-KNOWLEDGE.md) ซึ่งมีวันที่และที่มาระบุไว้ ไม่ใช่ฉบับสดหรือการรับรองจากผู้จัดทำต้นฉบับ รหัสรายการเป็นรหัสที่โครงการเพิ่มสำหรับ snapshot นี้

### English summary

The intended service offers a read-only curated checklist snapshot and Skills that run through a user-selected AI host. MCP accepts short keywords or selected item IDs; do not submit personal records or full lesson plans. GitHub Issues are public. Teachers retain professional judgment and must review suggestions and sources. The checklists are reflection aids, not official ratings or evidence of classroom outcomes. Provider terms apply to their respective services. Deployment status and settings require verification.
