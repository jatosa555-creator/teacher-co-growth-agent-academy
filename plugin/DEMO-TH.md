# Teacher Growth Partner — example prompts

These prompts illustrate intended Skill behavior. They are not observed model outputs or semantic test results.

When no task context is present, the three plain-language choices are **ช่วยเตรียมสอน**, **ช่วยดูงานที่สอนแล้ว**, and **ทำต่อจากครั้งก่อน**; map internally to Co-Design, Quick Check/Growth Coach, and supplied same-chat/carried context respectively.

1. **Quick Check:** “เมื่อวานฉันให้เด็กทำเครื่องบินกระดาษเป็นกลุ่ม มีเด็กสองคนทดลองตลอด อีกสองคนดูเฉย ๆ ฉันควรปรับตรงไหน?” Expected: one strength, possible blind spot as a hypothesis, one inclusive action, and evidence to observe.
2. **Growth Coach:** “ก่อนหน้านี้ฉันบรรยาย ตอนนี้ให้เด็กทดลองมากขึ้น ฉันภูมิใจที่เด็กกล้าถาม แต่ยังไม่รู้ว่าจะเก็บหลักฐานอย่างไร ช่วยสะท้อน 5 Shifts และทำแผนหนึ่งเป้าหมาย” Expected: five supplied labels, separate evidence/inference/unknown, no change claim beyond the teacher's account, one teacher-chosen trial.
3. **Co-Design:** “ช่วยปรับกิจกรรมกรองน้ำสำหรับ ป.6 ให้เชื่อมชีวิตจริง เด็กมีหลายบทบาท และใช้ AI ตรวจสอบข้อมูลอย่างรับผิดชอบ” Expected: one usable activity, realistic constraints or labeled assumptions, distinct classroom and AI lenses where relevant.
4. **Design Review:** “ช่วยดูแผนนี้แบบเร็ว แล้วเสนอจุดปรับที่คุ้มที่สุด” Expected: concise fast review, no unrequested rubric or score.
5. **Skill Builder:** “ช่วยทำขั้นตอน prompt ที่ช่วยฉันสรุปประเด็น PLC จากบันทึกที่เลือกเอง” Expected: produce a specific ready-to-use task prompt and editable context card; offer a native Skill draft only when the host supports it; never claim installation or sharing.
6. **Evidence/PLC:** “ช่วยสรุปไฟล์สองชิ้นที่ฉันเลือกให้เพื่อคุยใน PLC” Expected: review only selected authorized materials, disclose source coverage, anonymize, summarize shared themes without ranking individuals.
7. **Resume:** “ทำสรุปที่ฉันคัดลอกไปคุยต่อในแชทหน้า” Expected: copyable packet marked as teacher-carried context, with unknown fields left explicit and no memory claim.
8. **Timed artifact QA:** “ทำแผน 50 นาที” Expected: sum task durations including transitions, confirm exactly 50 minutes or revise, then show only the concise two-line check summary with the artifact.
