# Teacher Growth Partner — Plugin 1.2.0

**Teacher Co-Growth Agent Academy** เป็นชุด Skills สำหรับช่วยครูสะท้อนคิด ออกแบบการสอน และสร้างเครื่องมือการทำงานของตนเอง โดยครูเป็นผู้ตัดสินใจทุกขั้น

## เริ่มใช้งาน

เล่าความต้องการเป็นภาษาปกติได้เลย เช่น

- “ช่วยดูจุดแข็งกับสิ่งที่ฉันอาจมองข้ามจากกิจกรรมนี้”
- “ช่วยฉันสะท้อนการเปลี่ยนแปลงด้านการสอนและเลือกเป้าหมายหนึ่งข้อ”
- “ช่วยปรับกิจกรรมวิทย์ ป.6 ให้เด็กได้มีส่วนร่วมมากขึ้น”
- “ช่วยทำ Skill สำหรับขั้นตอนเตรียมประชุม PLC ของฉัน”
- “ช่วยรีวิวแผนนี้แบบเร็ว/แบบละเอียด”

ถ้าครูยังไม่ได้ระบุงาน ระบบจะแนะนำ 3 ทางเลือก:

1. **ช่วยเตรียมสอน** — สร้างหรือปรับกิจกรรมก่อนสอน
2. **ช่วยดูงานที่สอนแล้ว** — สะท้อนสิ่งที่เกิดขึ้นและเลือกก้าวถัดไป
3. **ทำต่อจากครั้งก่อน** — ใช้บริบทในแชทนี้ หรือวางข้อความสรุปจากแชทก่อน

ระบบจะเลือก Quick Check, Growth Coach หรือ Co-Design ตามงานที่ครูเล่า โดยไม่บังคับให้เลือกโหมดก่อนเริ่มช่วย

นอกจากนี้ยังมี Skill สำหรับรีวิวการออกแบบการสอน และช่วยทำ prompt ขั้นตอนเฉพาะที่ครูคัดลอกไปใช้ได้ทันที หาก host รองรับ Skills แบบ native จึงค่อยเสนอไฟล์ Skill เพิ่มเติม

## สิ่งที่รวมอยู่

- `skills/setup/SKILL.md` — แนะนำการเริ่มต้น
- `skills/teacher-growth/SKILL.md` — Quick Check, Growth Coach, Co-Design, การทบทวนหลักฐาน/PLC เมื่อครูร้องขอ
- `skills/teacher-design-review/SKILL.md` — รีวิวเร็วหรือเชิงลึก
- `skills/teacher-skill-builder/SKILL.md` — ทำ prompt ขั้นตอนงานที่คัดลอกใช้ได้ทันที พร้อม context card; เสนอ native Skill เมื่อ host รองรับ
- `skills/teacher-growth/references/` — 5 Shifts, checklist สองชุดที่แยกจากกัน, CoRel-5 และข้อจำกัดแหล่งข้อมูล
- `skills/teacher-growth/assets/` — แม่แบบ Growth Plan, lesson redesign และ context card
- `skills/teacher-growth/assets/resume-packet.md` — แม่แบบข้อความสำหรับครูคัดลอกไปใช้ในแชทถัดไป

## เช็กลิสต์ต้นฉบับสำหรับ AI

Classroom V8 58 ช่องรายการ พร้อมคู่มือภาพ 4 ช่วง; AI Practice 70 ข้อสะท้อนคิดและ 10 รายการหลักฐาน แยกเป็นไฟล์รายเสาใน references พร้อมรหัส หน้าและลิงก์ PDF ระบบเลือกเฉพาะข้อที่เกี่ยวข้อง ไม่โหลดทั้งหมดทุกคำตอบ เนื้อหาเป็น snapshot 23 ตุลาคม 2026 ไม่ใช่การอ่าน Drive สด ดู references/four-pillars.md และ references/ai-practice-four-pillars.md

## ขอบเขต

- ใช้ภาษาไทยเป็นค่าเริ่มต้นเมื่อครูสื่อสารภาษาไทย และถามไม่เกินหนึ่งคำถามสำคัญต่อรอบ
- 5 Shifts คือ Perspective, Affective, Process Thinking, System, Co-Growth; เป็นคำถามสะท้อนคิด ไม่ใช่คะแนนหรือหลักฐานยืนยันการเปลี่ยนแปลงรายบุคคล
- Classroom Practical Checklist และ AI Teacher Practice Checklist เป็นคนละชุด ห้ามรวมคะแนน ส่วน CoRel-5 เป็นกรอบคนละเรื่องกับ 5 Shifts
- ใช้เฉพาะหลักฐานที่ครูส่งหรือเลือกและอนุญาตให้ดู ระบุขอบเขตแหล่งข้อมูลว่าเต็ม/บางส่วน/ยังยืนยันไม่ได้
- ไม่ขอข้อมูลระบุตัวนักเรียนหรือข้อมูลส่วนบุคคลดิบ ไม่ค้น Drive ส่วนตัวอัตโนมัติ
- ไม่มีความจำข้ามแชท ไม่มีการติดตามอัตโนมัติ ไม่มีการติดตั้งหรือเผยแพร่ Skill ให้ครูโดยอัตโนมัติ
- Resume Packet และ Teacher Context Card เป็นข้อความให้ครูแก้ไขและคัดลอกเอง ไม่ใช่ระบบจัดเก็บถาวร
- คำแนะนำไม่ใช่การประเมินผลอย่างเป็นทางการ และไม่ยืนยันผลลัพธ์ผู้เรียนโดยไม่มีหลักฐาน

แพ็กเกจนี้เป็นชุดคำสั่ง Skill; ความสามารถจริงขึ้นกับ host ที่ติดตั้ง และไม่ได้เพิ่ม MCP server หรือการเชื่อมบัญชีภายนอก
