# Brand positioning | Teacher Co-Growth Agent Academy

- **Academy:** Teacher Co-Growth Agent Academy.
- **Product:** Teacher Growth Partner.
- **Capability:** reusable Skills that provide scoped instructions for teaching workflows.
- **One-line EN:** "A teacher growth partner for reflection, lesson design, and reusable teaching workflows."
- **One-line TH:** "คู่คิดเพื่อการเติบโตของครู ช่วยสะท้อนคิด ออกแบบการสอน และสร้างขั้นตอนการทำงานที่นำกลับมาใช้ได้"

## Truth in marketing

This package contains reusable skill instructions. A conversation can provide agent-like assistance, but it does not install an autonomous agent, establish durable memory, monitor classroom activity, read private Drive automatically, or track progress across unrelated chats. Any follow-up context must be supplied again or carried by the teacher in a copyable packet.
