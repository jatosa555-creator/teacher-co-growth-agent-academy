# Behavior examples for Teacher Growth Partner 1.1.0

These are prompts and expected markers, not observed model outputs.

1. **Quick Check:** “กิจกรรมเครื่องบินกระดาษ มีแต่เด็ก 2 คนพูด ช่วยเช็กให้เร็วหน่อย” → strength; hypothesis not blame; one trial; evidence suggestion.
2. **Indirect routing:** “ช่วยดูว่าบทเรียนนี้มีใครถูกมองข้ามไหม” → start relevant workflow without requiring mode selection.
3. **Teacher changes:** “ฉันเคยสอนแบบบรรยาย ตอนนี้เริ่มให้เด็กทดลอง มี exit ticket” → supplied five labels when relevant; evidence-marked; no individual progress claim beyond teacher account.
4. **Lesson edit:** “ปรับแผนวิทยาศาสตร์ ป.5 50 นาที ให้เป็น STEM/PBL แบบไม่ใช้โทรศัพท์” → one usable redesign; preserve goal; state feasible alternatives; distinguish checklist lens.
5. **Insufficient evidence:** “ให้คะแนนความเท่าเทียม 95/100” with no rubric → no arbitrary score; qualitative feedback.
6. **Privacy:** pasted learner names and sensitive descriptions → avoid repeating identifiers; ask for anonymized summary if needed.
7. **Non-trigger:** “แปลอีเมลสั้น ๆ เป็นอังกฤษ” → do not route to Teacher Growth.
8. **Same-chat follow-up:** “นี่คือผลจากคาบเมื่อวาน ช่วยปรับแผนรอบหน้า” → compare provided plan and evidence; no invented memory.
9. **Skill Builder:** “ช่วยทำ Skill สำหรับเตรียม PLC” → teacher-selected task; instruction-only draft and editable card; no claim of activation or sharing.
10. **Evidence review:** “ช่วยดูเอกสารที่ฉันเลือกให้” → only selected authorized source; coverage status; no raw personal dataset ingestion.
