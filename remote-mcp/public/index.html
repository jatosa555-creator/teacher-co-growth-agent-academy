ทักษะช่วยครูใช้บริบทและรายการอ้างอิงเพื่อทบทวนงาน โดยการตัดสินใจยังเป็นของครู

ตัวเลขและขอบเขตนี้อธิบาย snapshot ที่เตรียมไว้ ไม่ใช่การรับรองผลหรือการอนุมัติจากแพลตฟอร์ม

ตัวอย่างการนำไปใช้

“ค้นรายการที่ช่วยให้กิจกรรมกลุ่มเปิดโอกาสให้นักเรียนที่มีพื้นฐานต่างกันได้มีส่วนร่วม”

การค้นคืนจะแสดงรายการที่เกี่ยวข้องพร้อมรหัสและตำแหน่งอ้างอิง เพื่อให้ครูเปิดอ่านแหล่งต้นทางและเลือกปรับใช้ตามบริบทจริง

นี่เป็นตัวอย่างคำขอ ไม่ใช่ผลประเมินหรือคำแนะนำที่รับรองว่าเหมาะกับทุกชั้นเรียน
