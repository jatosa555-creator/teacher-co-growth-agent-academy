วิธีใช้และช่วยเหลือ

ขอบเขตการเชื่อมต่อ การค้นรายการ และทางเลือกเมื่อติดตั้ง MCP ไม่ได้

สถานะการติดตั้ง

การติดตั้งและการอนุมัติยังรอยืนยัน

ต้องเชื่อมต่อผ่าน MCP host ที่รองรับ และอาจต้องได้รับอนุมัติจากผู้ดูแลระบบหรือแพลตฟอร์ม หน้านี้ไม่ได้ยืนยันว่าเซิร์ฟเวอร์เปิดสาธารณะหรือติดตั้งได้แล้ว

สิ่งที่ MCP ทำได้

ส่งคำค้นสั้น ๆ หรือรหัสรายการเพื่อค้นหรือเปิดข้อมูลจากคลังที่คัดสรร ผลลัพธ์คาดว่าจะมีรหัสรายการและข้อมูลอ้างอิง เช่น แหล่งที่มาและหน้า PDF เพื่อช่วยตรวจสอบต้นทาง

  • ค้นรายการตามแนวคิดหรือคำสำคัญ
  • เปิดรายละเอียดด้วยรหัสรายการ
  • ใช้ผลลัพธ์เป็นจุดเริ่มต้นในการทบทวน โดยครูเป็นผู้เลือกและตัดสินใจ

เครื่องมือนี้ไม่สร้างแผนการสอน ไม่อ่านไฟล์ Drive ส่วนตัว ไม่จัดเก็บประวัติส่วนตัว และไม่รับข้อมูลนักเรียน

หากยังเชื่อมต่อไม่ได้

ใช้ข้อความด้านล่างกับผู้ช่วย AI ที่คุณใช้อยู่ แล้วตรวจสอบรายการและแหล่งอ้างอิงด้วยตนเอง ข้อความนี้เป็นทางเลือกแบบคัดลอก ไม่ได้เรียกใช้ MCP โดยอัตโนมัติ

ช่วยฉันทบทวนกิจกรรมการสอนเดิม โดยใช้รายการอ้างอิงจาก Teacher Growth Partner เมื่อเชื่อมต่อได้ หากยังเชื่อมต่อไม่ได้ ให้บอกตรง ๆ ว่าไม่มีคลังอ้างอิงและอย่าสร้างรหัสหรือแหล่งที่มาขึ้นเอง ถามฉันเพียงข้อมูลที่จำเป็น และเสนอทางเลือกเล็ก ๆ ที่ฉันเป็นผู้ตัดสินใจ

คำถามที่พบบ่อย

มีการเก็บข้อมูลที่ส่งค้นหาหรือไม่

แอปนี้ไม่ใช้บัญชีผู้ใช้ ฐานข้อมูล หรือ analytics ของตัวเอง และไม่ตั้งใจบันทึก request body ในโค้ด โฮสต์อาจเก็บ metadata เพื่อความปลอดภัยหรือการปฏิบัติการตามนโยบายผู้ให้บริการ โดยยังยืนยันระยะเวลาเก็บรักษาไม่ได้ ดูรายละเอียดที่หน้า ความเป็นส่วนตัว

ฉันควรส่งข้อมูลอะไร

ส่งเฉพาะคำค้นสั้น ๆ หรือรหัสรายการ อย่าส่งชื่อนักเรียน แผนการสอนฉบับเต็ม หรือข้อมูลส่วนบุคคล
