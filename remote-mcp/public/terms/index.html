เงื่อนไขการใช้

ร่างข้อมูลสำหรับผู้ใช้ Teacher Growth Partner เพื่ออธิบายขอบเขตของเครื่องมืออย่างตรงไปตรงมา

ผู้เผยแพร่: CHANON PHAJUNDA · Teacher Co-Growth Agent Academy

บริการนี้ทำอะไร

Teacher Growth Partner เป็นเครื่องมือ MCP แบบอ่านอย่างเดียวสำหรับค้นหาและเปิดรายการในชุด checklist ที่คัดสรร ผลลัพธ์อาจแสดงรหัสรายการ แหล่งที่มา และตำแหน่งหน้า PDF เพื่อให้ตรวจสอบเอกสารต้นทางได้

การใช้ข้อมูลอย่างเหมาะสม

ใช้คำค้นสั้น ๆ หรือรหัสรายการเท่านั้น อย่าส่งข้อมูลระบุตัวนักเรียนหรือบุคคล แผนการสอนฉบับเต็ม หรือข้อมูลที่เป็นความลับ

การตัดสินใจของครู

รายการอ้างอิงเป็นข้อมูลประกอบการทบทวน ไม่ใช่คะแนนหรือคำรับรองคุณภาพ ครูต้องพิจารณาความเหมาะสมกับบริบทและเป็นผู้ตัดสินใจว่าจะนำไปใช้อย่างไร

การเข้าถึงและสถานะ

การเชื่อมต่อขึ้นอยู่กับ MCP host และการตั้งค่าหรือการอนุมัติที่เกี่ยวข้อง การเผยแพร่ การอนุมัติ และความพร้อมให้ใช้งานอาจเปลี่ยนแปลงได้ หน้านี้ไม่ได้ยืนยันสถานะเหล่านั้น

ร่างฉบับนี้

เอกสารนี้ยังรอผู้เผยแพร่ทบทวนให้ตรงกับบริการและโฮสต์จริง ก่อนนำไปใช้เป็นเงื่อนไขฉบับสมบูรณ์ ไม่มีการระบุเขตอำนาจศาลหรือข้อผูกพันทางกฎหมายในร่างนี้

ช่องทางติดต่อผู้เผยแพร่: รอผู้เผยแพร่ระบุ

สถานะ: ร่างเพื่อทบทวนข้อเท็จจริง ไม่ใช่คำรับรองทางกฎหมายหรือการรับรองมาตรฐาน
